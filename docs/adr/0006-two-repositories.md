# Two repositories: a public showcase written by agents, a private study repo written by the owner

The owner wants both speed (to publish) and depth (to learn). One repository cannot serve both: agent-written code moves fast but teaches little, and hand-written learner code is slow and not showcase quality. So `doom-player` is public and agent-written, and `doom-player-study` is private and owner-written. Study guides live in the public repo under `docs/learn/`, because a clear explanation of the code is itself portfolio material; the owner's attempts and notes stay private.

## Consequences

The repositories share no code. Each has its own `CLAUDE.md` with opposite instructions about handing over solutions.
