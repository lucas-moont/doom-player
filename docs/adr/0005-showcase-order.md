# The LLM-only Contender is built before any reinforcement learning

Teaching order would start with simple RL and reach LLMs near the end. This repository is also a portfolio with a need to publish early, and the owner already has LLM access through a CLI subscription. So the public order is: workshop, Eval Suite and MCP server, LLM-only on `E1M1`, then the RL ladder, then the hybrid. The first post reports a measured result on a question people already care about, and sets up the rest of the series.

Teaching order is preserved in the private study repository, which follows its own curriculum at the owner's pace.

## Consequences

The Eval Suite and MCP server (M1) are built before any Contender exists, so they are validated with a random agent.
