# Beat the game is measured at Difficulty 3

"Beat the game" (`CONTEXT.md`) is a Campaign that Clears every required Map of its scope, and it now has a fixed Difficulty: 3, "Hurt Me Plenty", the default choice in the original game's menu. Every Map Eval Spec so far (`e1m1-v1`) and every Map Scoreboard row is at Difficulty 3, so the goal ladder is measured on the same footing as everything before it. A result at another Difficulty is allowed, for example a curriculum stage at Difficulty 1 (M4 brief), but it gets its own Eval Spec name and never counts toward Beat the game. Proposed after M4 and accepted by the owner on 2026-10-04.

## Considered Options

- **Ultra-Violence (4)**, the Difficulty speedrunners and many players treat as the "real" game: a stronger claim, but it would leave every result to date on a different footing, and no Contender has yet been measured at it.
- **Leave it open**: each milestone would pick its own Difficulty, and the final claim could be argued either way.

## Consequences

- The Bonus Doom Episode and any harder Difficulty are stretch results, reported separately.
- By convention an Eval Spec's name changes whenever its Difficulty does (`eval.EvalSpec`), so a Difficulty 4 result is never mistaken for a Difficulty 3 one.
